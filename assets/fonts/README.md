# Bundled Roboto font

`Roboto-Variable.ttf` is the normal Roboto variable font (`wdth`, `wght`)
from the official Google Fonts repository. It is bundled so Flutter Web does
not fetch the default text font from Google at runtime.

- Source commit: `ec626514f79f831f1ab848a82114a0ce7e2d6372`
- Repository: <https://github.com/google/fonts>
- Source path: `ofl/roboto/Roboto[wdth,wght].ttf`
